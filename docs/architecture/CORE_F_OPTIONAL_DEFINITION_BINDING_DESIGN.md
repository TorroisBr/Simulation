## Public node accessibility correction

Public graph properties and constructor accessibility are intentionally asymmetric for selected graph nodes: callers may read immutable public node instances from public `IReadOnlyDictionary` maps, while only Core's graph factory (internal constructors) can mint the canonical instances. The optional local descriptors are deliberately different: their current direct-blueprint API accepts descriptors without a catalog, so the pure immutable value constructors are public, store raw values, and perform no validation. The explicit command catalog remains responsible for its own existing nonempty/duplicate ID rule. The Unity adapter preserves source-object aliases only within a conversion batch; there is no global interner.
